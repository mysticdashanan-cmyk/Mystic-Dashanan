FREE PUBLISHING WITH GITHUB PAGES:
1. Sign in or create a free account at https://github.com/
2. Create a new repository named mystic-dashanan (Public).
3. Upload index.html and the assets folder (keep the folder structure exactly the same).
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The URL will be shown in Settings -> Pages, usually:
   https://YOUR-USERNAME.github.io/mystic-dashanan/

Cost: $0 for a public static site on GitHub Pages. A custom .com domain is optional and normally costs extra.
